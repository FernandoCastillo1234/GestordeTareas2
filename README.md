proyecto de introducción al curso 2026/2027
To Do
crear pequeña aplicacion para gestionar un listado de tareas.

Funcionalidades Base:
- Añadir tareas
- Eliminar tareas
- Ver tareas
- Marcar tareas como completadas

Nuevas Funcionalidades Añadidas:
- Asignación de prioridad (Alta, Media, Baja) al crear una tarea.
- Filtro para ver las tareas según su prioridad.
- Exportación y guardado del listado actual en un archivo 'tareas.txt'.

Implementación
se usa la ultima version de java Jdk27.
Almacenamiento de tareas en la memoria usando ArrayList y manipulación de Strings para los estados y prioridades.
Gestión de UI con print y Scanner.
Exportación a texto plano usando FileWriter.
