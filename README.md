## To Do
crear pequeña aplicacion para gestionar un listado e tareas.
## Funcionalidades
1. Añadir tareas
2. Eliminar tareas
3. Tareas completadas
4. Marcar tareas como completadas
## implementación
- se usa la **ultima verdion de java** Jdk27.
- Almacenamiento de tareas en la memoria usando `ArrayList`.
- Gestión de UI con `print` y `Scanner`.
